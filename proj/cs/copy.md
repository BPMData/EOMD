# CS living poster: card copy (draft for Bryan's review)
 
## Layout
- Each bloom shows **three separate cards at once**, one per language, never interleaved. Each card sprouts from its own fiddlehead.
- Every language always gets the **same color and the same position** in the trio (EN · ES · PT), so students find their card without reading the others.
- Each card has a small language label: English / Español / Português. No flags, because language ≠ country.
- Cards are short (title + 1–3 lines) and smaller than today's SSR card. The trio's footprint should be **no bigger than one current card** (about 1100×760 on a 1920×1080 board), leaving the vines visible.
- Cards cycle in the order below. `code` marks monospace text.
## Cards
 
### 1. Variables
- **EN:** Math vs. Code / In math, you solve for x. In code, you set x.
- **ES:** Matemáticas vs. código / En matemáticas, despejas x. En programación, tú le das el valor a x.
- **PT:** Matemática vs. código / Na matemática, você descobre o valor de x. Na programação, você define o valor de x.
### 2. Loops
- **EN:** FOR or WHILE? / FOR: you know how many times. WHILE: repeat until something changes.
- **ES:** ¿FOR o WHILE? / FOR: sabes cuántas veces. WHILE: repite hasta que algo cambie.
- **PT:** FOR ou WHILE? / FOR: você sabe quantas vezes. WHILE: repita até algo mudar.
### 3. Functions
- **EN:** Functions = Recipes / Write the steps once. Use them again and again.
- **ES:** Funciones = recetas / Escribe los pasos una vez. Úsalos una y otra vez.
- **PT:** Funções = receitas / Escreva os passos uma vez. Use quantas vezes quiser.
### 4. Check the worksheet
- **EN:** Check the Worksheet / The answer is probably in the worksheet. Check it first!
- **ES:** Revisa la hoja / La respuesta probablemente está en la hoja de trabajo. ¡Revísala primero!
- **PT:** Confira a folha / A resposta provavelmente está na folha de atividades. Confira primeiro!
### 5. One change at a time
- **EN:** One Change at a Time / Change one thing. Test. Repeat.
- **ES:** Un cambio a la vez / Cambia una cosa. Prueba. Repite.
- **PT:** Uma mudança por vez / Mude uma coisa. Teste. Repita.
### 6. 3 before me
- **EN:** Stuck? 3 Before Me / 1. Check the worksheet. 2. Check your code. 3. Ask someone at your table. Then ask me!
- **ES:** ¿Te atascaste? 3 antes de mí / 1. Revisa la hoja. 2. Revisa tu código. 3. Pregunta a alguien de tu mesa. ¡Luego pregúntame a mí!
- **PT:** Travou? 3 antes de mim / 1. Confira a folha. 2. Confira seu código. 3. Pergunte a alguém da sua mesa. Depois, pergunte para mim!
### 7. What went wrong?
- **EN:** What Went Wrong? / Read the error message. No error? Watch what your code actually does.
- **ES:** ¿Qué salió mal? / Lee el mensaje de error. ¿No hay error? Mira lo que tu código hace de verdad.
- **PT:** O que deu errado? / Leia a mensagem de erro. Sem erro? Veja o que o seu código realmente faz.
### 8. Write your own code
- **EN:** Write Your Own Code! / That's how you learn.
- **ES:** ¡Escribe tu propio código! / Así se aprende.
- **PT:** Escreva seu próprio código! / É assim que se aprende.
### 9. Small errors add up
- **EN:** Small Errors Add Up / Check your starting point first.
- **ES:** Los errores pequeños se suman / Revisa primero tu punto de partida.
- **PT:** Pequenos erros se somam / Confira primeiro seu ponto de partida.
### 10. Bugs are normal
- **EN:** Bugs Are Normal / Every programmer debugs every day.
- **ES:** Los bugs son normales / Todo programador depura código todos los días.
- **PT:** Bugs são normais / Todo programador depura código todos os dias.
### 11. Log every attempt
- **EN:** Log Every Attempt / Write down what failed and why.
- **ES:** Anota cada intento / Escribe qué falló y por qué.
- **PT:** Registre cada tentativa / Anote o que falhou e por quê.
### 12. Clear names
- **EN:** Clear Names / Give your variables obvious names. Call your robot's speed `robot_speed`, not `rs`, `motion` or `x`.
- **ES:** Nombres claros / Ponles nombres obvios a tus variables. A la velocidad de tu robot llámala `robot_speed`, no `rs`, `motion` ni `x`.
- **PT:** Nomes claros / Dê nomes óbvios às suas variáveis. Chame a velocidade do seu robô de `robot_speed`, não de `rs`, `motion` ou `x`.
### 13. Comment your code
- **EN:** Comment Your Code / Future You will thank you.
- **ES:** Comenta tu código / Tu "yo" del futuro te lo agradecerá.
- **PT:** Comente seu código / O seu "eu" do futuro vai agradecer.
### 14. Coming soon: text coding
- **EN:** Coming Soon: Text Coding / Loops, variables, functions, if/then and more: everything you learn now will help you when we start typing code!
- **ES:** Pronto: programar con texto / Bucles, variables, funciones, if/then y más: ¡todo lo que aprendes ahora te ayudará cuando empecemos a escribir código!
- **PT:** Em breve: programação em texto / Loops, variáveis, funções, if/then e mais: tudo o que você aprende agora vai ajudar quando começarmos a digitar código!
## Python cards (hold until text coding starts; add with a build setting)
 
### P1. Indentation
- **EN:** Indentation Matters / Python reads the spaces. Indented lines belong to the line above them.
- **ES:** La sangría importa / Python lee los espacios. Las líneas con sangría pertenecen a la línea de arriba.
- **PT:** A indentação importa / O Python lê os espaços. Linhas indentadas pertencem à linha de cima.
### P2. `=` vs `==`
- **EN:** `=` vs `==` / `=` stores a value. `==` asks a question.
- **ES:** `=` vs `==` / `=` guarda un valor. `==` hace una pregunta.
- **PT:** `=` vs `==` / `=` guarda um valor. `==` faz uma pergunta.
### P3. Text vs. numbers
- **EN:** `"5" + "5" = "55"` / Text sticks together. Numbers add: `5 + 5 = 10`.
- **ES:** `"5" + "5" = "55"` / El texto se une. Los números se suman: `5 + 5 = 10`.
- **PT:** `"5" + "5" = "55"` / Texto se junta. Números se somam: `5 + 5 = 10`.
